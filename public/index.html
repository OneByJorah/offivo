Offivo

An animated 3D virtual office for Hermes AgentOS subagents. Watch your AI agents work, walk, and collaborate in real-time.

Enter 3D Office View Architecture GitHub
Features

Everything you need to
monitor your agent fleet

Offivo transforms agent observability into an immersive 3D experience.

🧑‍💻

3D Agent Visualization

Animated avatars showing agents working, walking, meeting, and interacting in a detailed office environment.

⚡

Real-Time Updates

SSE, API polling, and webhook push — multiple channels for live agent state synchronization.

🖱️

Interactive UI

Click-to-inspect agents, camera zoom/rotate, chat bubbles, and detailed stats panels for every agent.

🏢

Detailed Environment

Server room, meeting area, kitchen, lounge, phone booths, ping pong table, and individual workstations.

🔌

Multiple Data Sources

Bridge script, API polling, static JSON, and webhooks — feed agent data from any source.

🐳

Zero-Dependency Server

Pure Python stdlib HTTP server. No pip install needed. One-command deployment with Docker Compose.
